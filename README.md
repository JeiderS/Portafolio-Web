🎨 Portafolio Web
🚀 Portafolio personal desarrollado con HTML, CSS y JavaScript, con animaciones fluidas mediante Keyframes y un formulario de contacto funcional con EmailJS.

🔹 Características
🎬 Animaciones dinámicas con CSS Keyframes.
📩 Formulario de contacto funcional con EmailJS.
🎨 Diseño moderno y responsivo, adaptable a cualquier dispositivo.
⚡ Optimización de rendimiento, asegurando una carga rápida.
🌐 Interactividad con JavaScript para mejorar la experiencia del usuario.


📦 Tecnologías Utilizadas
✅ HTML5
✅ CSS3 (Keyframes para animaciones)
✅ JavaScript (para interacción)
✅ EmailJS (para el formulario de contacto)
